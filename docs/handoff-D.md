# Передача D и демонстрация

В локальной ветке `D` сохранена объединённая история Ananas/dev/vadim и реализован полный путь D. Закрыты прежние недочёты связи ФСП ID, live-подбора, фильтров, истории и перехода из потребности в приглашение. Контракты/TypeScript актуальны; новый Alembic head — `0013_fsp_searches`. Применённые миграции сохранены.

## Запуск

Из корня репозитория:

```sh
cp .env.example .env
python3 scripts/dev.py
```

Приложение — http://localhost:8080, Swagger — http://localhost:8080/api/docs, локальные письма — http://localhost:8025. Подтвердите адрес по письму Mailpit, затем войдите. Данные сохраняются в PostgreSQL volume; `docker compose down` без `-v` их сохраняет.

На рабочем компьютере при занятом порте API 8000 используется внешний локальный override с портом 8010. Он не нужен для обычного чистого запуска.

## Проверенный сценарий

1. Зарегистрировать кандидата `demo-fsp-winner+<уникальная-метка>@example.com` и работодателя с другим вымышленным адресом; подтвердить письма Mailpit.
2. Кандидату сохранить профиль и контакты, явно согласиться на обработку. На странице ФСП связать предзаполненный собственный demo-ID. На экране показаны синтетическое происхождение и достижения.
3. Выбрать видимые технологии и согласие публикации. Пройти настоящий опрос/тест B и подтвердить результат; до категории публикация недоступна работодателю.
4. Работодателю создать компанию и потребность: Backend Middle, Python, навык `api.idempotency`, описание задач и диапазон зарплаты.
5. Открыть подбор: реальный опубликованный кандидат, категория и score/причины, без ФИО/контактов. Уточнить стек/FSP-фильтр, сохранить новый поиск, вернуться к исходному через историю.
6. Нажать «Пригласить» на карточке. Описание, зарплата и основания из потребности предзаполнены. Отправить предложение без вакансии.
7. Кандидату открыть условия и принять с явным разрешением передать контакты этой компании. Работодателю обновить предложение и получить контакты. Чужая компания получает отказ в доступе.
8. Отозвать доступ к контактам: endpoint закрывается, повтор accept его не восстанавливает. На отдельном предложении отказ не создаёт grant.
9. Скрыть профиль: он исчезает из live и сохранённых подборок, прежний снимок приглашения остаётся. Удалить связь FSP; основной путь без истории продолжает работать.
10. Скачать личный PDF; работодатель и чужой кандидат не могут его скачать.

Автоматизация этого пути: `cd apps/web && npm run test:e2e`. Подробная изолированная проверка D: `npm run test:e2e:d`; она запускает отдельные API/Vite на 8078/8079 с тестовой БД и контролируемыми портами B/C.

## Почта

По умолчанию Mailpit перехватывает письма локально: они не пересылаются в Gmail/Яндекс. Для повторного подтверждения уже зарегистрированного адреса используйте «Отправить письмо повторно» на `/check-email`.

Для настоящей доставки задайте в локальном `.env` `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_USER`, `SMTP_PASSWORD` и один из `SMTP_STARTTLS=true` (обычно порт провайдера 587) либо `SMTP_SSL=true` (обычно 465). Параметры определяет выбранный провайдер. Затем пересоздайте API: `docker compose up -d api`. `docker-compose.yml` передаёт эти значения в приложение; реальных SMTP-реквизитов в репозитории нет. Для публичного размещения установите HTTPS, корректный `PUBLIC_APP_URL` и `COOKIE_SECURE=true` по README.
