# Статус D

Срез локальной реализации от 8 октября 2026 года. Реализованы профиль/контакты, приватность/согласия, публичная проекция, приглашения/решения/события, права контакта, PDF и интерфейсы двух ролей. Собственные части этапов 2–7 персонального плана реализованы; материалы передачи (этап 8) подготовлены. Полное закрытие этапов требует настоящих B/C, общего G1/G2, независимого CI/запуска и передачи A. Эти результаты пока не подтверждены.

## Ограничения и интеграция

Без настоящего B категория null; согласие на публикацию можно принять, но профиль не виден работодателям. Без company_id/C отправка закрыта (`COMPANY_REQUIRED`/503). Отсутствие ФСП не влияет на основной путь, UI показывает unavailable при отсутствии C. Тестовый e2e_app не является composition root продукта.

P1 вакансии/самостоятельные отклики, ATS и автоматическое распознавание PDF не реализованы: план допускает их только после P0 всех участников. Настоящий общий E2E (реальный тест B → подбор C → приглашение D) зависит от B/C. Отдельные FK к компании/потребности ждут таблиц C. Удалённый CI нового кода не запускался; workflow включает D E2E. Изменения не закоммичены и не отправлены на GitHub.

Есть прежнее предупреждение Starlette о TestClient/HTTPX; тесты проходят. Повторяемый тестовый seed работает только на явно именованной test БД, не публикует synthetic подтверждения в рабочем приложении.

Дополнительный аудит: `test_d_contracts.py` проверяет актуальность всех D OpenAPI-операций, request/response/error/PDF, общую Salary, запрет лишних полей и обязательный timezone дат. `FspEvidence.fetched_at` также требует timezone. Seed использует фиксированное время и детерминированные UUID согласий/событий/grants; повтор сохраняет внесённые владельцем изменения и отзывы. T01/T02/P01/P02/P03 явно перечислены в фикстурах.
