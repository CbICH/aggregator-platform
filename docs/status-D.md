# Статус D

Срез реализации — 10 октября 2026. Обязательные функции D01–D10 реализованы в локальной ветке `D`: ручной профиль/контакты/PDF, согласия и приватность, безопасная публичная проекция, адресное приглашение без вакансии, зарплата и условия, статусы обеих сторон, принятие/отказ, контактные права и отзыв, интерфейс связи с ФСП ID. Закрыты прежние интеграционные недочёты C/D: связь ID и `FspRead`, live-ranking, пять фильтров, история подборок и переход в приглашение.

ФСП использует явно отмеченный синтетический реестр. Реальные кандидаты приложения проходят настоящее тестирование B; достижения берутся из фиксированных серверных demo-записей, а не из формы кандидата. История ФСП не обязательна. См. [fsp.md](fsp.md).

## Проверки

| Проверка | Результат |
|---|---|
| API SQLite | 149 тестов пройдены |
| API PostgreSQL в отдельной test-БД | 149 тестов пройдены, включая гонки приглашений/отзыва/idempotency |
| Docker + PostgreSQL + Chromium + Mailpit | 4 сценария, включая реальный B → FSP → потребность C → live-подбор/история → приглашение/контакты/отзыв D |
| Изолированный подробный D E2E | Две компании, публикация, принятие, контакты, отзыв, отказ, PDF |
| Миграции | Шесть исходных состояний SQLite; сохранение аккаунта, профиля, компании, опроса и существующей потребности; единый head `0013_fsp_searches` |
| PostgreSQL migrations | Upgrade/check/downgrade до core/upgrade/check на отдельной временной БД |
| Ruff, формат, OpenAPI/JSON/TypeScript | Пройдены; схемы и клиентские типы актуальны |
| Typecheck и production build | Пройдены |
| Чтения небольшого стенда | 20 параллельных клиентов, 120 запросов, все HTTP 200; 7 профилей, p95 431 мс |

На стенде применена новая ревизия `0013_fsp_searches`, старые миграции не переписывались. Скрытие/отзыв повторно проверяются при чтении сохранённой подборки. Она хранит только запрос, копию потребности и UUID кандидатов; контакты и скрытые значения не копируются.

## Передача

Матрица требований: [requirements-D.md](requirements-D.md). Демонстрация/запуск: [handoff-D.md](handoff-D.md). Сопроводительная документация: [D-report.pdf](D-report.pdf). Текущее исправление проверено локально; удалённый CI для него появится после публикации, которая требует команды пользователя.

Внешний API ФСП, публичный хостинг, финальная презентация всей команды, полевые измерения валидности тестов B и необязательные MVP-функции (вакансии/отклики/ATS/распознавание PDF) не следует объявлять выполненными результатами D. Для внешней почты нужен SMTP-провайдер; локальная доставка и подтверждение проверяются в Mailpit.
