# Подготовка к сдаче

## Сопроводительная документация всей платформы

[Итоговый PDF](<Сопроводительная документация ФСП Сигнал.pdf>) охватывает все восемь обязательных тем §3.4 ТЗ; [DOCX](<Сопроводительная документация ФСП Сигнал.docx>) предназначен для редактирования, [Markdown](project-documentation.md) содержит текст. Документ включает A/B/C/D, полный перечень 57 операций API, версии, команды запуска и фактические результаты проверки. Синтетический реестр и отсутствие измеренного пилота с людьми обозначены явно.

## Материалы D

Исходники, OpenAPI/JSON schemas/TypeScript, миграции, API/браузерные тесты и инструкции включены в проект. [Сопроводительный PDF](D-report.pdf) пригоден для передачи как раздел документации команды. [Сценарий демонстрации](handoff-D.md) проходит весь обязательный путь, [матрица требований](requirements-D.md) связывает его с проверками.

## Проверяемый результат

- Кандидат сохраняет собственный профиль и PDF, явно выбирает согласия/публичные поля.
- Реальное тестирование B определяет категорию; ручной грейд не управляет ranking.
- ФСП ID связывается только с собственным аккаунтом демонстрационного реестра, достижения берутся с сервера; кандидат без истории поддержан.
- Потребность работодателя порождает объяснимый live-подбор с пятью фильтрами и историей.
- Адресное приглашение содержит компанию, описание и RUB-зарплату; контакты доступны только принявшей компании и отзываются.

Локально пройдены 149 API-тестов на каждой СУБД, четыре production браузерных сценария и отдельный D E2E, миграции/check/откат, Ruff, актуальность схем, TypeScript и production build. Обновлённая версия не объявляется прошедшей GitHub CI до её публикации.

## Командная сдача

Организатор сдачи добавляет обязательную презентацию команды, ссылку на публикуемый коммит/репозиторий, доступный жюри прототип либо видео и инструкцию локального запуска. Презентация должна честно назвать FSP-данные синтетическими, показать алгоритм ranking, обработку отсутствия ФСП, результаты и границы валидации B. Развёртывание, SMTP-реквизиты и результаты пилота не подменяются локальными тестами D.

Для демонстрации без внешнего SMTP открывайте Mailpit http://localhost:8025. Настройка внешней доставки описана в [handoff-D.md](handoff-D.md), публичного сервера — в README. Приватные `.env`, локальные БД, токены, дампы, журналы и AI-артефакты не включаются в сдаваемый Git.
