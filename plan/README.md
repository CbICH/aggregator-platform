# Рабочий пакет «ФСП Сигнал»

Подготовлен по всем девяти страницам исходного ТЗ. Это план разработки, а не реализованный прототип или отчёт о проведённых измерениях.

1. [Основной план](01-План-разработки.md) — идея, сценарии, приоритеты, механики тестирования и подбора, архитектура, график, валидация и матрица 49 требований.
2. [Задачи четырёх участников](02-Задачи-команды.md) — распределение, оценки времени, зависимости и критерии приёмки.
3. [Общие контракты](03-Контракты-и-правила.md) — данные, API, внутренние интерфейсы, статусы, транзакции и фикстуры.
4. [Единый PDF](../output/pdf/ФСП-Сигнал-план-команды.pdf) — все три документа для чтения и передачи команде.

Рабочие допущения: 48 часов, FastAPI + React, три разработчика ведут функциональные модули целиком, четвёртый занимается координацией, каркасом и интеграцией. Фактические сроки и опыт команды пока не указаны. Перед стартом заменить A/B/C/D именами, подтвердить сроки и при необходимости адаптировать стек. Контракты и распределение сохраняются при замене технологий.

Приоритеты: P0 — обязательно; P1 — только после работающего P0; P2 — концепция развития. Целевые метрики в документах не являются измеренными результатами.
