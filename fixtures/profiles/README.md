# Синтетические сценарии D

`scenarios.json` — тестовые данные, не результаты настоящих участников ФСП.
Seed находится в `apps/api/tests/seed_d.py`, разрешён только для явно именованной
test БД и не импортируется production-приложением. Повтор не изменяет существующие
строки: заполненный профиль, скрытие и отзыв контактов сохраняются.

UUID кандидатов/компаний/приглашений заданы в JSON; UUID согласий/событий/grants
детерминированно получаются из ключа сценария. Время задано `fixed_time`, второе
событие происходит через пять минут. Даты результатов B в контролируемом
`AssessmentDouble` также фиксированы. Пароль хешируется с новой случайной солью.

| Сценарии | Проверяемое состояние |
|---|---|
| D01 | Опубликован, ФСП не связан |
| D02 | Опубликован, видны только роли |
| D03 | Email не подтверждён |
| D04 | Публикация отозвана |
| D05 | Подтверждённая тестовая категория и длинное резюме |
| E01/E02 | Изолированные компании |
| I01/I02 | Отправлено/просмотрено, контакты закрыты |
| I03/I04 | Принято с grant / отклонено без grant |
| T01/T02 | Идемпотентность / гонка принятия и отказа |
| P01/P02/P03 | Неверный диапазон зарплаты / без вакансии / отзыв после снимка |

T/P — команды и проверки, не искусственные успешные строки БД. Их входные значения
и имена тестов перечислены в `checks`; P03 проверяет старую публичную проекцию и
новое чтение D после отзыва. Поведение настоящей сохранённой подборки C требует
отдельного интеграционного сценария с реальным C.
